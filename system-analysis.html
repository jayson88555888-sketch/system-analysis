What is System Analysis?

System analysis is the process of studying a problem, understanding the current system, identifying requirements and defining what a new or improved system should accomplish.

A system analyst may study:

  • Current system problems
  • User requirements
  • Business processes
  • Data and information flow
  • System constraints
  • Possible improvements

🔄 System Development Life Cycle

1

Planning

Identify the problem, objectives and project scope.

2

Analysis

Study requirements, problems and information needs.

3

Design

Define how the proposed system will work.

4

Implementation

Build, install and deploy the new system.

5

Testing

Check whether the system works according to requirements.

6

Maintenance

Maintain, support and improve the system.

📋 System Requirements

⚙️ Functional Requirements

Describe what the system should do. For example, a student system may allow users to register, log in, view results and update information.

🛡️ Non-Functional Requirements

Describe qualities and constraints of the system, such as security, performance, usability and reliability.

🔎 Information Gathering

🗣️

Interview

Talk directly with users, staff or stakeholders to understand their needs.

📝

Questionnaire

Collect information from multiple people using structured questions.

👀

Observation

Observe how users perform their current tasks and processes.
